# YVJPARFUM

Plataforma digital de YVJPARFUM, emprendimiento de perfumería en República Dominicana.

## Componentes
- **backend/**: API REST en ASP.NET Core (.NET 10) + SQL Server
- **web/**: sitio web en Next.js + TypeScript
- **mobile/**: app Android en Flutter
- **docs/**: arquitectura, decisiones y bitácora de aprendizaje
